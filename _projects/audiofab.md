**AudioFab** is an open-source agent framework that uses natural-language instructions to select and coordinate audio tools.
Its modular architecture separates tool dependencies and supports tasks across speech, sound and music.

The accompanying **ACM Multimedia 2025** paper is a collaboration involving Jing Han and colleagues at Hunan University and the University of Cambridge.

- [Paper and DOI](https://doi.org/10.1145/3746027.3756869)
- [Author-deposited version](https://arxiv.org/abs/2512.24645)
- [Source code and documentation](https://github.com/SmileHnu/AudioFab)

See the original repository for supported tasks and usage instructions.
